Approval Flow

Every action. Every time. You decide what runs.

One-Use IDs

Each approval request gets a cryptographically random ID (e.g., k7m9x2). Once used or expired, it's invalid forever. No replay attacks.

5-Minute Expiry

Approval requests auto-expire after 5 minutes. Stale requests can't be approved later. Forces timely decisions.

Risk Classification

Actions tagged: Low (navigate, scroll, read), Medium (type, click), High (form submit, download, auth). You see the risk before deciding.

Reasoning Display

Each request shows: what the agent wants to do, why it thinks it's necessary, and what the risk is. Full transparency.

Batch Approve

Approve multiple low-risk actions at once: approve k7m9x2 p4n8q1 r3t5w7. Saves clicks for repetitive tasks.

Deny with Reason

Deny requests with a note that feeds back to the planner: deny k7m9x2 "already on that page". Agent learns.

Architecture

FastAPI approval server + Browser Use driver + Pluggable LLM providers.

LLM Providers

Two adapters. One interface. Swap without code changes.

OpenAI Adapter

GPT-4o, GPT-4o-mini, GPT-4-turbo. Function calling, vision, streaming. Set OPENAI_API_KEY.

Ollama Adapter

Llama 3.1, Mistral, CodeLlama, Qwen2.5. Fully local. No API keys. Set OLLAMA_HOST (default http://localhost:11434).

Model Selection

Auto-selects based on task complexity. Simple navigation → small model. Complex reasoning → large model. Configurable thresholds.

Test Suite

Three test modules. Mock browser driver. No external dependencies.

smoke_browser.py

End-to-end browser automation with mock driver. Navigation, clicks, typing, extraction.

test_upstream_contract.py

Validates compatibility with Browser Use 0.13.10 API. Catches breaking changes early.

test_workspace.py

Workspace isolation tests. Separate browser profiles, cookie stores, permissions per session.
