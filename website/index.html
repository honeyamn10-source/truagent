LLM agents on the Python standard library alone.

TruAgent is a tiny, dependency-free framework for building agents in Python. A clean think → call → observe → answer loop, automatic tool schemas, any OpenAI-compatible backend, and built-in retries, hooks and memory.

Install View on GitHub
truagent/example.py
from truagent import Agent, Memory, OpenAICompatibleClient, tool

@tool
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b

agent = Agent(
    llm=OpenAICompatibleClient(
        base_url="http://localhost:11434/v1",  # Ollama
        model="qwen2.5",
    ),
    tools=[add],
    memory=Memory(system="You are a precise calculator."),
)

print(agent.run("What is 12345 + 54321?"))
# agent: calls add(12345, 54321) -> 66666

Capabilities

Everything an agent needs, with zero magic

Each capability is a small module (agent.py, clients.py, memory.py, middleware.py, parse.py, tools.py) covered by its own test file.

🔄

The agent loop

A clean think → call a tool → observe → answer cycle driven by Agent, with a max_steps guard so agents cannot run wild.

🏷️

Automatic tool schemas

Decorate a function with @tool and the JSON schema is reflected from type annotations and docstrings — descriptions, defaults, required vs optional. No hand-written schema.

🧩

Any model backend

OpenAI, Ollama, Anthropic, vLLM, LM Studio, Groq, Together — anything speaking the OpenAI-compatible protocol. Local backends need no API key.

🧠

Memory

Ordered conversation history with a stable system prompt, so context survives across turns.

↻

Retries with backoff

RetryPolicy applies exponential backoff to transient failures — network blips don't kill a run.

👀

Hooks

Observe every step and every message (on_step, on_message) for logging, tracing or streaming.

✍️

Bring your own backend

BaseLLM is a single method: write a working chat backend in ~20 lines.

⌘

A real CLI

truagent run "…" --model … --base-url … --max-steps N runs agents without touching Python code.

Core concepts

Six moving parts you can hold in your head

ConceptWhat it is
AgentDrives the loop: prompt → model → tool calls → answer.
@toolTurns any Python function into an LLM-callable capability.
MemoryOrdered conversation history with a stable system prompt.
BaseLLMThe interface every backend implements (write your own in ~20 lines).
RetryPolicyExponential backoff for transient failures.
HooksObserve every step and message in the loop.
One dependency is worth a lot here. A framework that ships with zero runtime dependencies installs in seconds, works offline, has a tiny honest supply-chain surface and never locks you into a vendor — for you or your users.
Internals & tests

Small modules, exact responsibilities

ModuleResponsibility
agent.pyThe loop, step counting, tool dispatch and answer assembling.
clients.pyOpenAICompatibleClient (stdlib urllib), default headers and retry scheduling.
tools.pySchema reflection from type hints and docstrings.
memory.pyMessages, system prompt and history helpers.
middleware.pyRetries and hooks wired into the loop.
parse.pyRobust JSON/tool-call extraction from model output.

Installation

Installation is the whole point

Install from source (verified)

git clone https://github.com/honeyamn10-source/truagent.git
cd truagent
python -m venv .venv && source .venv/bin/activate
pip install -e .
truagent version

Zero-dependency guarantee

No requests, no httpx, no pydantic, no SDKs. The framework uses only the Python standard library — auditable, offline-friendly and secure by construction.

pip install -e ".[dev]"
pip check        # no broken dependencies
pytest           # 108 passing
