Core Concepts

Five primitives. That's it. Everything else is composition.

BaseLLM

Abstract interface. Implement generate(messages, tools) for any provider. Includes MockLLM for testing.

@tool Decorator

Turn any function into a callable tool. Automatic schema extraction from type hints and docstrings.

Agent

Orchestrates the loop: LLM → tool calls → results → LLM. Configurable max steps, streaming, callbacks.

Memory

Conversation history with automatic summarization. Pluggable backends (in-memory, SQLite, custom).

RetryPolicy

Exponential backoff, jitter, configurable exceptions. Applies to LLM calls and tool executions.

Hooks

Lifecycle events: on_llm_start, on_llm_end, on_tool_start, on_tool_end, on_error. Async supported.

Tool System

The @tool decorator handles schema generation, validation, and execution automatically.

tools.py
from truagent import tool from typing import Annotated @tool def search_web( query: Annotated[str, \"Search query\"], max_results: Annotated[int, \"Max results (1-10)\"] = 5 ) -> list[dict]: \"\"\"Search the web and return results.\"\"\" ... @tool async def fetch_url( url: Annotated[str, \"URL to fetch\"], timeout: float = 10.0 ) -> str: \"\"\"Fetch and extract text from a URL.\"\"\" ... # Schema auto-generated: # { # "name": "search_web", # "description": "Search the web and return results.", # "parameters": { # "type": "object", # "properties": { # "query": {"type": "string", "description": "Search query"}, # "max_results": {"type": "integer", "default": 5} # }, # "required": ["query"] # } # }

Memory System

Conversation history with automatic summarization and pluggable storage.

In-Memory

Default. Fast, ephemeral. Perfect for single-session agents.

SQLite Backend

Persistent across sessions. SQLiteMemory(\"agent.db\"). Includes conversation search.

Summarization

Auto-summarizes old messages when token budget exceeded. Configurable threshold and model.

Custom Backends

Implement MemoryBackend protocol. Redis, PostgreSQL, vector stores — your choice.

memory.py
from truagent import Memory, SQLiteMemory # In-memory (default) memory = Memory() # Persistent SQLite memory = SQLiteMemory(\"conversations.db\") # Add messages manually memory.add_user_message(\"Hello\") memory.add_assistant_message(\"Hi there!\") # Get conversation for LLM messages = memory.get_messages() # Search history results = memory.search(\"weather\") # Auto-summarization memory = Memory(summarize_after=4000, summary_model=llm)

RetryPolicy & Hooks

RetryPolicy

policy = RetryPolicy(
    max_attempts=3,
    base_delay=1.0,
    max_delay=30.0,
    exponential_base=2,
    jitter=True,
    retry_on=(ConnectionError, TimeoutError)
)

Hooks

hooks = {
    "on_llm_start": lambda ctx: log(ctx),
    "on_llm_end": lambda ctx, resp: metrics.record(resp),
    "on_tool_start": lambda ctx: trace(ctx),
    "on_tool_end": lambda ctx, result: None,
    "on_error": lambda ctx, err: alert(err),
}

agent = Agent(llm, tools, hooks=hooks)

Examples

Chat Bot

agent = Agent(llm, tools=[], memory=Memory())
while True:
    user = input("You: ")
    if user == "quit": break
    print(agent.run(user).final_answer)
